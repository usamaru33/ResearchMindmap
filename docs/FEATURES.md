# 機能一覧（研究者・論文執筆者向け）

研究活動の流れ（**探す → 読む・整理する → 関係を理解する → 書く → 共有する**）に沿って、必要な機能をできる限り挙げた。

- **優先度**: P0 = 必須（今回の要件そのもの）/ P1 = 高 / P2 = 中 / P3 = 将来
- **状態**: ☐ 未着手 / ◐ 進行中 / ☑ 完了
- 実装の順番と PR の対応は [ROADMAP.md](./ROADMAP.md) を参照

## A. 探す（検索・収集）

| ID | 機能 | 優先度 | 状態 | 概要 |
|---|---|---|---|---|
| A1 | 横断クエリ検索 | P0 | ☑ | RQL（ACM/IEEE 形式のブール検索）で OpenAlex・Semantic Scholar・Crossref・arXiv・PubMed・IEEE・DBLP を並列に検索 |
| A2 | 検索結果からマップ生成 | P0 | ☑ | 引用関係・トピッククラスタ・根ノードを自動で作り、自動配置 |
| A3 | なんとなく検索 | P0 | ☐ | 自然文（日本語可）の説明から、意味検索・LLM によるクエリ展開・再ランキングで論文を探す |
| A4 | クエリ構文チェック | P1 | ☑ | 入力中に構文エラーの位置を表示し、ソースごとに近似される箇所を警告 |
| A5 | 出版社・年・OA 絞り込み | P1 | ☑ | `publisher:acm` / `year:2020..` / `oa:true` を UI のチップでも指定 |
| A6 | 識別子から追加 | P1 | ☐ | DOI / arXiv ID / URL / タイトルを貼り付けて論文を取り込む |
| A7 | 引用展開（スノーボーリング） | P1 | ☐ | ノードから参考文献（後方）・被引用（前方）を取得してマップに追加 |
| A8 | 関連論文の推薦 | P1 | ☐ | 選択した論文群に似た論文を提案（S2 推薦 / OpenAlex 意味検索） |
| A9 | 検索履歴・保存クエリ | P2 | ☐ | 実行したクエリと件数を記録し、再実行・比較できる |
| A10 | 重複統合 | P0 | ☑ | DOI・arXiv ID・正規化タイトルで同じ論文をまとめる |
| A11 | 新着アラート | P3 | ☐ | 保存クエリの新着を定期的に確認（OpenAlex alerts） |
| A12 | 著者・会議から探す | P2 | ☐ | 著者や会議名でまとめて取得し、その人の研究の流れを表示 |

## B. 読む・整理する（ライブラリ管理）

| ID | 機能 | 優先度 | 状態 | 概要 |
|---|---|---|---|---|
| B1 | プロジェクトの保存・切替 | P0 | ☑ | 複数のマップをローカルに保存（現状はリロードで消える） |
| B2 | 読書状態 | P1 | ☐ | 未読 / 読書中 / 読了 / スキップ |
| B3 | タグ・メモ・評価 | P1 | ☐ | 自由タグ、Markdown メモ、星評価 |
| B4 | ライブラリ一覧 | P1 | ☐ | 表形式で全論文をソート・絞り込み（年・被引用数・状態・タグ） |
| B5 | PDF・ランディングへのリンク | P1 | ☐ | OA の PDF、DOI、arXiv へのリンク |
| B6 | AI 要約・翻訳 | P2 | ☐ | 抄録の日本語要約・翻訳、要点の箇条書き（LLM） |
| B7 | スクリーニング（系統的レビュー） | P2 | ☐ | 採用 / 除外 / 保留と除外理由。PRISMA 用の件数集計 |
| B8 | 比較表（文献マトリクス） | P2 | ☐ | 論文 × 観点（手法・データセット・評価・課題）の表。CSV 出力 |

## C. 関係を理解する（可視化・分析）

| ID | 機能 | 優先度 | 状態 | 概要 |
|---|---|---|---|---|
| C1 | 色分けの切替 | P1 | ☐ | 年 / クラスタ / 読書状態 / ソースで色分け |
| C2 | ノードの大きさ = 被引用数 | P1 | ☐ | 影響力を一目で把握 |
| C3 | マップ内検索・フィルタ | P1 | ☐ | 文字列・年範囲・タグで強調表示 / 非表示 |
| C4 | 時系列レイアウト | P2 | ☐ | 年を横軸に並べ、研究の系譜を見る |
| C5 | 重要論文の検出 | P2 | ☐ | マップ内の被引用数（内部次数）で「基礎論文」「最新の発展」を印付け |
| C6 | 研究ギャップの抽出 | P2 | ☐ | 各論文の課題・今後の展望を集約し、未解決の問題を整理（LLM） |
| C7 | クラスタ名の自動命名 | P2 | ☐ | クラスタ内の論文から LLM が名前を付ける |
| C8 | 共著ネットワーク | P3 | ☐ | 著者ノードと共著エッジの表示 |

## D. 書く（執筆支援）

| ID | 機能 | 優先度 | 状態 | 概要 |
|---|---|---|---|---|
| D1 | BibTeX 出力 | P1 | ☐ | 選択論文・全論文を `.bib` で出力（引用キー自動生成） |
| D2 | 参考文献の書式コピー | P1 | ☐ | APA / IEEE / ACM 形式で文字列コピー |
| D3 | 関連研究の下書き生成 | P2 | ☐ | 選択論文とクラスタ構造から Related Work の下書きを生成（LLM、ストリーミング、引用キー付き） |
| D4 | RIS / CSV 出力 | P2 | ☐ | Zotero・Mendeley・EndNote 連携用 |
| D5 | BibTeX / RIS 取り込み | P2 | ☐ | 既存の文献リストをマップに取り込む |
| D6 | 研究課題の整理 | P3 | ☐ | 研究ギャップ（C6）から研究課題・貢献の案を出す |

## E. 共有・操作性

| ID | 機能 | 優先度 | 状態 | 概要 |
|---|---|---|---|---|
| E1 | JSON エクスポート / インポート | P1 | ☑ | プロジェクトの丸ごとバックアップ・共有 |
| E2 | マップの画像出力 | P2 | ☐ | PNG / SVG（発表資料用） |
| E3 | 元に戻す / やり直す | P2 | ☐ | Ctrl+Z / Ctrl+Shift+Z |
| E4 | キーボードショートカット | P2 | ☐ | 検索欄へ移動、削除、配置など |
| E5 | 削除時の整合性修正 | P0 | ☑ | 引用エッジやノードを削除したときに `references` と選択状態を正しく更新 |
| E6 | TB レイアウトのハンドル位置 | P1 | ☑ | 上下方向の配置でハンドルを上下に置く |
| E7 | 設定画面 | P2 | ☐ | 使うソースの選択、ソースごとの件数、LLM の有効/無効、API の状態表示 |
| E8 | UI の日本語化 | P3 | ☐ | 日本語と英語の切替 |
